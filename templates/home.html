About the project

A practical ML project built around content discovery.

This machine learning project recommends both movies and web series. The engine compares title information such as genres, keywords, cast, crew, and overview text to find closely related content.

It demonstrates a complete workflow: preparing entertainment data, converting text features into numerical vectors, measuring similarity, and presenting the results through a Flask web application.
